| | |
|---|---|
| **Human problem** | Hearing 'AI agent' everywhere without knowing what's inside one. |
| **Objective** | Authority; prepares buyers for agent projects |
| **Hook** | What's inside an AI agent (4 parts) |
| **Main idea** | An agent = model + instructions + memory + tools; fewer tools mean fewer mistakes. |
| **Key value** | Plain-language anatomy that helps buyers scope agent projects. |
| **Takeaway (what did I just learn?)** | An AI agent is a model plus instructions, memory and tools, and fewer tools means fewer mistakes. |
| **CTA** | None. Ends with a practical question to ask anyone selling an 'AI agent'. |
| **Visual concept** | Robot outline split into four labelled zones (head, notebook, chat bubble, toolbox). |

**On-image copy (use exactly)**

- **Headline:** What's inside an AI agent (4 parts)
- **Body:**
  - Brain: the AI model that reads and decides.
  - Instructions: the rules, written once (tone, limits, when to ask a human).
  - Memory: what it remembers about this customer or task.
  - Tools: what it may do. Read a sheet, send a message, book a slot.
- **Footer:** Fewer tools = fewer mistakes. Give an agent only what it needs.
- **Layout:** Dark background. Simple line-art agent figure in the centre with four callout lines to labelled boxes (brain/head, instructions/clipboard, memory/notebook, tools/toolbox). Footer bottom.

**Caption**

```text
“AI agent” sounds complicated. Inside, it's 4 parts:

🧠 Brain: the AI model that reads and decides
📋 Instructions: the rules, written once (tone, limits, when to hand over to a human)
🗂 Memory: what it remembers about this customer or task
🧰 Tools: what it's allowed to do (read a sheet, send a message, book a slot)

The rule I build by: fewer tools = fewer mistakes. Give an agent only what it needs for the job.

Next time someone sells you an “AI agent”, ask which tools it's allowed to use.

#AIagents #n8n #automation
```
