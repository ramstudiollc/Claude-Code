## 18:30 · Image · D21-I2: Make your Google Sheet automation-ready: 5 rules

**Series:** Automate This · **Content type:** Automation & n8n · **Format:** Annotated spreadsheet

- **The problem it solves:** Automations breaking because the spreadsheet behind them is messy.
- **The idea:** Clean structure (one header row, one record per row, stable column names, consistent formats, an ID column) prevents automation failures.
- **What they leave with:** One header row, one record per row, stable column names, one date format and an ID column keep a sheet automation-ready.
- **Call to action:** Save: Save it before you share a sheet with anyone who automates.

**Text on the image** (use exactly)

- Headline: Make your Google Sheet automation-ready
- Body:
  - One header row. No merged cells.
  - One row = one order, one customer, or one lead.
  - Never rename a column without telling whoever built the automation.
  - Dates in one format (2026-10-31). Phone numbers as text.
  - Add an ID column so nothing gets counted twice.
- Footer: A clean sheet is half the automation.

**What the image shows:** Clean spreadsheet mock with numbered callouts on the header row, an ID column and date format.

**Layout idea** (your brand guidelines decide colours and fonts): Light background. Mock spreadsheet top half with numbered callout circles pointing at header, a row, a column name, a date cell and an ID column. Rules listed below with matching numbers.

**Caption** (copy and paste)

```text
Automations read your Google Sheet like a machine. Make it easy:

1. One header row. No merged cells.
2. One row = one record (one order, one customer, one lead)
3. Never rename a column without telling whoever built the automation

5. Add an ID column so nothing gets counted twice
```
