## 21:00 · Reel · D11-R2: Why automations break, and the alert that saves you

**Series:** Automate This · **Content type:** Automation & n8n · **Format:** Talking head + screen split · **Length:** 45 s

- **The problem it solves:** An automation silently stops working and you find out from an unhappy customer.
- **The idea:** Expired logins, changed data and silent failures break automations; an n8n error workflow alerts you immediately.
- **Hook (first 3 s):** I build automations. Every one will break.
- **What the viewer wants to know:** When does it break, and how do I find out first?
- **Where it pays off:** 22–38 s: an n8n error workflow messages you the moment a linked workflow fails.
- **What they leave with:** Set an n8n error workflow so any failure sends you an alert instead of staying silent.
- **Call to action:** Question to the viewer: Ask n8n builders whether their workflows have an error workflow set.
- **Overall look:** Canvas nodes turning red for each failure; renamed column; calendar of silent days; Error Trigger → phone alert.

**Video script** (times in seconds; say the voiceover word for word)

| Time | Voiceover (say) | On-screen text | What to show |
|---|---|---|---|
| 0-2.5 | I build automations. Every one will break. | Every automation breaks | Asif; behind him a canvas node flashes red. |
| 2.5-7 | One: a login expires. A password changes, or a token runs out. | 1 · Logins expire | Key icon cracks. |
| 7-12.5 | Two: the data changes. Someone renames a column in the sheet. | 2 · A column gets renamed | Sheet header 'Phone' edited to 'Mobile No.'; node turns red. |
| 12.5-17 | Your workflow still looks for “Phone”. It finds nothing. | Looks for 'Phone' → nothing | Empty output panel. |
| 17-22 | Three, the worst one: it fails quietly, and nobody notices for a week. | 3 · It fails quietly | Calendar days flip; unread orders pile up. |
| 22-27.5 | The fix in n8n: an error workflow. It starts the moment a workflow fails. | Fix: an error workflow | Error Trigger node on canvas. |
| 27.5-33 | It sends me a message: which workflow, which step, what went wrong. | Which workflow · step · why | Telegram alert on phone. |
| 33-38 | Set it once in workflow settings. It covers every workflow you link to it. | Set once in Settings | Workflow Settings → 'Error workflow' dropdown. |
| 38-42 | No alert means you find out from an angry customer. | No alert = angry customer | Asif to camera. |
| 42-45 | Test it: break one on purpose. | Test the alert | End card. |

**Why people keep watching**
- Hook: An automation builder admitting everything breaks is unexpected and builds trust instantly.
- Curiosity: Viewers want to know the three moments it breaks, especially 'the worst one'.
- Relatability: Renaming a sheet column is something every team does without thinking.
- Problem → solution: Each failure is followed by the n8n fix (error workflow) shown on screen.
- Payoff: A real alert message arrives on the phone with workflow, step and error.

**Caption** (copy and paste)

```text
I build automations, and every one of them will break eventually. Usually for one of 3 reasons:

1. A login expires (password changed, token ran out)
2. The data changes (someone renames a sheet column, a form adds a question)
3. It fails quietly, and nobody notices for a week. This is the worst one.

The fix in n8n: an error workflow. Create a workflow that starts with the Error Trigger node and sends you a message (Telegram, email, chat). Then select it under Workflow Settings → Error workflow for each workflow you care about.

No alert = you find out from an angry customer.

If you build in n8n: does every workflow you care about have an error workflow set?

#n8n #automation #nocode
```

**Notes:** Demo on a test workflow: rename a column live to trigger the failure. Show the Error Trigger workflow and a real alert. Hide chat IDs and tokens.
