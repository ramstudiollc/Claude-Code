## 13:30 · Reel · D30-R1: What is JSON? A tiffin box with labels

**Series:** Explain It Simply · **Content type:** Automation & n8n · **Format:** Prop explainer + talking head · **Length:** 30 s

- **The problem it solves:** Seeing curly brackets in automation tools and feeling locked out.
- **The idea:** JSON stores data as labelled compartments (keys and values, including lists); automations pass these boxes between steps; missing or renamed labels break workflows.
- **Hook (first 3 s):** JSON is a tiffin box with labels.
- **What the viewer wants to know:** How is a tiffin box like data?
- **Where it pays off:** 3–25 s: labels and contents, lists, and why a missing label breaks a step.
- **What they leave with:** JSON is labelled data passed between automation steps, and most breaks come from a missing or renamed label.
- **Call to action:** Question to the viewer: Ask which Explain It Simply helped most.
- **Overall look:** Real multi-compartment tiffin box with sticky labels; JSON text overlay mirroring the compartments; n8n data panel.
- **Loop:** Ends 'So next time you see curly brackets, just think…' over the tiffin box, which completes into the opening 'JSON is a tiffin box with labels.'

**Video script** (times in seconds; say the voiceover word for word)

| Time | Voiceover (say) | On-screen text | What to show |
|---|---|---|---|
| 0-3 | JSON is a tiffin box with labels. | JSON = labelled tiffin box | Asif opens a multi-compartment tiffin box with sticky labels. |
| 3-7 | Each compartment has a label, and something inside. | label → contents | Labels 'rice', 'dal', 'fish' close-up. |
| 7-11.5 | In JSON: name is Rahim. Phone, this number. Item, a shirt. | name: Rahim · item: shirt | JSON text overlay mirrors the compartments. |
| 11.5-15.5 | One compartment can hold a list. Shirt, cap, belt. | items: [shirt, cap, belt] | One compartment holds three small items. |
| 15.5-20 | Every automation passes boxes like this from one step to the next. | step → box → step | n8n data panel showing JSON between nodes. |
| 20-25 | When a workflow breaks, it's often a missing label, or a renamed one. | Missing label = broken step | A label is torn off; a node turns red. |
| 25-30 | So next time you see curly brackets, just think… | { } | Back to the tiffin box, same framing as frame 1 (loop). |

**Why people keep watching**
- Hook: A playful, local analogy for a technical term, unexpected and memorable.
- Visual progression: A real tiffin box opens compartment by compartment while JSON appears beside it.
- Novelty: Few people have seen JSON explained with something from their own kitchen.
- Rewatch: The final line loops back into the opening line.
- Usefulness: Explains why renamed labels break workflows, connecting to earlier lessons.

**Caption** (copy and paste)

```text
What is JSON? A tiffin box with labels.

Each compartment has a label and something inside:
name → Rahim
phone → 01XXXXXXXXX
items → [shirt, cap, belt] (one compartment can hold a list)

Every automation passes “boxes” like this from one step to the next. When a workflow breaks, it's often because a label is missing or was renamed (remember the renamed sheet column?).

That's the last Explain It Simply this month. Which one helped you most?

#JSON #n8n #automation
```

- **What they leave with:** Describe a task with its trigger, steps, what-ifs and result so anyone can quote or build it.
- **Call to action:** Question to the viewer: Invite viewers to write their task in this format in the comments; Asif replies.

## 21:00 · Reel · D30-R2: What do you repeat every day? The open offer

**Series:** Work With Me · **Content type:** Work with me (n8n services) · **Format:** Talking head + montage · **Length:** 36 s

- **The problem it solves:** Repeating the same tasks every day without knowing if they can be automated.
- **The idea:** After a month of examples, invite viewers to send one repetitive task by voice note; Asif replies personally with an honest verdict, which is sometimes 'don't automate'.
- **Hook (first 3 s):** What do you repeat every single day?
- **What the viewer wants to know:** What happens if I send my task?
- **Where it pays off:** 17–32 s: a personal reply, three questions and an honest verdict, which is sometimes no.
- **What they leave with:** Send one repetitive task as a voice note and get an honest answer on whether it's worth automating.
- **Call to action:** Message me (service): Message 'AUTOMATE' with a voice note describing the task.
- **Overall look:** Close-up talking head; quick montage of earlier Reels' own footage; Messenger icon.
- **Loop:** Ends 'So, before you scroll away, tell me:' which loops into the opening question.
