## 21:00 · Reel · D29-R2: Auto-reply to comments in Messenger: the rules you must know

**Series:** Automate This · **Content type:** Automation & n8n · **Format:** Diagram explainer + talking head · **Length:** 45 s

- **The problem it solves:** Answering the same 'price?' comment by hand, again and again.
- **The idea:** A Page can send one private reply per comment within 7 days; a reply opens a 24-hour window; comment-bait is demoted.
- **Hook (first 3 s):** Hundreds of “price?” comments. Replying one by one?
- **What the viewer wants to know:** Can I automate this without breaking Facebook's rules?
- **Where it pays off:** 8–33.5 s: one private reply per comment, within 7 days, a 24-hour window if they reply, and no comment-bait.
- **What they leave with:** A Page can send one private reply per comment within seven days, so make that first message genuinely useful.
- **Call to action:** Soft service line: Soft service line in the caption only.
- **Overall look:** Comment 'Price?' → private reply in Messenger; three rule cards; red 'comment-bait' card; n8n canvas.

**Why people keep watching**
- Hook: Starts with the repetitive chore page owners face daily before introducing the rules.
- Novelty: Most viewers don't know the one-message, 7-day limit.
- Usefulness: Three rules + how to write the one message that matters.
- Problem → solution: Shows the risk (bait, rule breaks) and the compliant approach.
- Relatability: 'Price?' comments under posts are everywhere on Bangladeshi pages.

**Caption** (copy and paste)

```text
Hundreds of “price?” comments, and you reply to each one by hand? You can automate it, but know Meta's rules first:

1. One private reply per comment
2. It must be sent within 7 days of the comment
3. If they reply, a 24-hour window opens and you can keep chatting

So make the first message count: the price, a link, and one question back.

And don't ask people to comment just to boost reach. Facebook demotes engagement bait.

I build comment replies in n8n with the official Messenger API, inside these rules. If your page needs one, send me a message.

#MessengerAutomation #n8n #FacebookTips
```
